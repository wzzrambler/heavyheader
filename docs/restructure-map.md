# 章节映射：完整版 → 精简评审版

> 目的：证明「压缩」是**转移**而不是**删除**。任何实验、负面结果或证据出处，
> 都可以按本表从精简版回查到完整版或仓库文件。
>
> 生成方式：`python docs/make_pdf_review.py`（精简版）、
> `python docs/make_pdf.py`（完整版）。两版共用同一批实测数字，精简版不新增数据。
>
> **自本轮起，章节映射表只放在本文件里**：精简版正文不再占用两页放映射，
> PDF 末页只留一行指向这里的链接。本文件随作品材料一同提交，评审可查。
